# 드론 조종기 입력

드론 조종기를 이용한 로봇의 수동 조종 방법을 정의한다. 이 문서에서 사용하는 몸체 원점, 몸체 원점 좌표계, 몸체 기준점 및 몸체 기준 좌표계는 [좌표축 README](../README.md#몸체-좌표계)의 정의를 따른다.

로봇의 이동은 현재 몸체 원점을 기준으로 수행한다. 로봇이 이동하지 않은 상태에서 몸체 원점의 위치나 몸체의 자세만 변경하는 동작은 로봇의 이동에 포함하지 않는다.

## 짐벌 입력

스위치 SA를 사용하여 짐벌 입력을 조종 모드와 보정 모드 사이에서 전환한다.

### 조종 모드

조종 모드에서는 로봇의 이동 속도와 몸체의 roll·pitch 각도를 명령한다.

| 입력 채널 | 기능 |
|---|---|
| 스로틀 | 현재 몸체 원점 좌표계의 x축 방향 전진·후진 선속도를 명령한다. |
| yaw | 현재 몸체 원점을 지나는 z축을 기준으로 좌우 회전 각속도를 명령한다. |
| roll | 몸체 원점 좌표계를 기준으로 몸체의 roll 각도를 명령한다. |
| pitch | 몸체 원점 좌표계를 기준으로 몸체의 pitch 각도를 명령한다. |

### 보정 모드

보정 모드에서는 몸체 기준 좌표계를 기준으로 몸체 원점의 이동 속도와 몸체의 yaw 각도를 명령한다.

| 입력 채널 | 기능 |
|---|---|
| 스로틀 | 몸체 기준 좌표계의 z축 방향으로 몸체 원점의 이동 속도를 명령한다. |
| yaw | 몸체 기준 좌표계를 기준으로 몸체의 yaw 각도를 명령한다. |
| roll | 몸체 기준 좌표계의 y축 방향으로 몸체 원점의 이동 속도를 명령한다. |
| pitch | 몸체 기준 좌표계의 x축 방향으로 몸체 원점의 이동 속도를 명령한다. |

보정 모드에서는 몸체의 roll과 pitch 각도를 각각 0°로 유지한다.

## 스위치 입력

| 스위치 | 기능 |
|---|---|
| SA | 짐벌 입력의 조종 모드와 보정 모드를 전환한다. |
| SD | 킬 스위치로 사용한다. |
| SB | 착지, 수동 조종 및 자율 주행 모드를 선택한다. |
| SE | 몸체 원점을 몸체 기준점으로 이동하고 몸체의 roll·pitch·yaw 각도를 각각 0°로 복귀시킨다. |

수동 조종은 드론 조종기를 이용하여 로봇을 조종하는 모드이다.
