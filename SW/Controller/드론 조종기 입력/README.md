# 드론 조종기 입력

RadioMaster Pocket ELRS 조종기로 육각보행 로봇에 전달할 사용자 명령을 정의한다. 이 문서는 채널 배치, 입력값 규격, 모드별 조작법과 입력 보호 동작만 다룬다. 제어기 내부 계산은 [Controller_detail.md](../Controller_detail.md), 몸체 축의 정의는 [좌표축 README](../좌표축/README.md)를 따른다.

## 1. 사용 장비와 통신

| 항목 | 사양 |
|---|---|
| 조종기 | RadioMaster Pocket ELRS, Mode 2 |
| 수신기 | DarwinFPV 2.4G ELRS Nano |
| 무선 링크 | ELRS 2.4 GHz |
| 수신기 출력 | CRSF UART |
| STM32 UART | USART6 RX, PC7 |
| UART 설정 | 420000 baud, 8-N-1 |
| 제어 주기 | 5 ms, 200 Hz |

USART6 TX인 PC6은 현재 조종기 수신에 필요하지 않다. 자세한 STM32 설정은 [STM32F446RE 설정 정리본](../../STM32/STM32F446RE%20설정%20정리본.md#10-usart6--radiomaster-pocket-elrs--elrs-nano-수신기)을 따른다.

## 2. CRSF 채널 배치

EdgeTX 전용 모델의 `Mixes`를 다음과 같이 설정한다. 수신기가 채널 기능을 고정하는 것이 아니므로 새 모델을 만들거나 설정을 복사한 뒤에는 반드시 조종기 채널 모니터에서 순서를 다시 확인한다.

| CRSF 채널 | EdgeTX Source | Pocket 입력 | 제어기 입력 |
|---:|---|---|---|
| CH1 | Ail | 오른쪽 짐벌 좌우 | Roll |
| CH2 | Ele | 오른쪽 짐벌 상하 | Pitch |
| CH3 | Thr | 왼쪽 짐벌 상하 | Throttle |
| CH4 | Rud | 왼쪽 짐벌 좌우 | Yaw |
| CH5 | SA | 2단 스위치 | SA, `0/1` |
| CH6 | SB | 3단 스위치 | SB, `0/1/2` |
| CH7 | SC | 3단 스위치 | SC, `0/1/2` |
| CH8 | SD | 2단 스위치 | SD, `0/1` |
| CH9 | SE | 순간 버튼 | SE, `0/1` |
| CH10 | S1 | 가변 입력 | 예비, 현재 미사용 |
| CH11~CH16 | - | - | 미사용 |

CH1~CH4는 `AETR` 순서이다. 물리 스위치의 위·가운데·아래 위치가 논리값 `0/1/2` 중 어느 값으로 들어오는지는 실제 조종기 시험에서 확인한다.

## 3. 입력값 규격

### 3.1 짐벌 값

CRSF에서 해석한 네 짐벌 채널은 STM32에서 다음 공통 형식으로 변환한다.

| 항목 | 값 |
|---|---:|
| 최소 | `-1000` |
| 중립 | `0` |
| 최대 | `1000` |
| 제어기 정규화 범위 | `-1.0~1.0` |

Throttle도 중립이 `0`인 양방향 값으로 사용한다. 따라서 별도 방향 스위치 없이 양수와 음수로 전진·후진 또는 상승·하강을 모두 명령한다.

현재 입력 전처리 초기값은 다음과 같다.

| 항목 | 현재 값 | 의미 |
|---|---:|---|
| Throttle Dead Zone | `±20 raw` | 중립 부근 스로틀 입력을 0으로 처리한다. |
| Yaw/Roll/Pitch Dead Zone | `±50 raw` | 중립 부근 짐벌 입력을 0으로 처리한다. |
| LPF Cutoff | `5 Hz` | Dead Zone 이후의 네 짐벌 입력을 평활화한다. |

Dead Zone 밖의 남은 범위는 다시 `-1.0~1.0`으로 선형 정규화한다. 실제 조종기가 준비되면 채널별 최소값·중립값·최대값·방향을 설정 테이블에 기록하고 위 값은 실측 결과에 맞춰 조정한다.

### 3.2 연속 입력 규칙

실제 짐벌처럼 명령이 시간에 따라 연속적으로 변하도록 한다. 임시 조종기 입력과 시험 입력은 raw 변화율을 `5000/s`로 제한한다.

| 변화 구간 | 소요 시간 |
|---|---:|
| `0 → ±1000` | `0.2 s` |
| `-1000 ↔ 1000` | `0.4 s` |
| 5 ms당 최대 변화량 | `25 raw` |

SA~SE는 디지털 입력이므로 Ramp 없이 즉시 전환한다.

강화학습 출력도 Throttle·Yaw·Roll·Pitch의 독립된 스칼라 명령을 사용하고 동일한 변화율 제한을 거친다. Step Action을 발끝 위치, 관절각 또는 사용자 명령 경로에 직접 전달하지 않는다.

### 3.3 입력 상태 초기화

조종 모드와 보정 모드처럼 짐벌의 의미가 달라지는 상태로 전환할 때는 새 명령을 계산하기 전에 네 짐벌 필터 상태를 모두 0으로 초기화한다. 조종 모드에서 SA가 바뀔 때는 이전 Yaw 회전 명령이 횡이동 명령으로 이어지거나 그 반대가 되지 않도록 Yaw 필터 상태를 0으로 초기화한다.

## 4. 스위치 기능

최종 조종기 기능과 현재 구현 상태를 구분한다.

| 스위치 | 최종 기능 | 현재 구현 상태 |
|---|---|---|
| SA | 조종 모드 이동 방식 선택, 암 모드 그리퍼 개폐 | 조종 모드 기능만 구현됨 |
| SB | 착지·수동 조종·자율주행 선택 | `1`은 서기·READY 유지, `0/2`는 착지 요청으로 처리함 |
| SC | 조종·암·보정 모드 선택 | `0`은 조종, `1`은 명령 없는 READY, `2`는 보정으로 처리함 |
| SD | Kill 요청 | `1`일 때 Kill을 요청함 |
| SE | 자세·Heading 기준값 초기화 | `1`일 때 초기화를 요청함 |

현재 조종 모드에서 SA가 `0`이면 x축 이동과 Yaw 회전을 사용하고, `1`이면 Heading을 유지하며 x·y축으로 이동한다. SA는 보정 모드의 이동 방향을 선택하지 않는다. 암 모드와 자율주행은 최종 채널 배치를 유지하되 제어 코드는 추후 구현한다.

## 5. 조종 모드

조종 모드에서는 로봇의 이동 속도와 몸체 자세를 명령한다. 좌표계는 `+X 전진`, `+Y 왼쪽`, `+Z 위쪽`을 사용한다.

| 입력 | SA 상태 | 명령 | 최대값 |
|---|---|---|---:|
| Throttle | 공통 | x축 전진·후진 속도 | `±0.28 m/s` |
| Yaw | `0` | 몸체 Yaw 각속도 | `±45 deg/s` |
| Yaw | `1` | y축 좌·우 이동 속도 | `±0.28 m/s` |
| Roll | 공통 | 몸체 Roll 목표각 | `±45 deg` |
| Pitch | 공통 | 몸체 Pitch 목표각 | `±45 deg` |

SA가 `0`이면 Yaw 짐벌을 움직이는 동안 목표 Heading이 회전하고, 짐벌을 중립으로 놓으면 그 시점의 Heading을 유지한다. SA가 어느 방향으로 바뀌든 전환 시점의 현재 Yaw를 새 목표 Heading으로 잡는다.

SA가 `1`이면 Yaw 짐벌은 회전이 아니라 y축 이동을 명령한다. 사용자 Yaw 각속도는 0으로 두고 전환 시점의 Heading을 유지한다.

Roll·Pitch의 사용자 입력 범위는 `±45 deg`이지만 실제 적용 명령은 현재 발 위치의 IK 작업공간을 넘지 않도록 제한된다. 여러 자세축이 동시에 입력되면 결합된 명령 전체를 적용할 수 있을 때만 갱신하고, 불가능하면 직전 유효 명령을 유지한다.

보행은 다음 중 하나가 충족될 때 시작된다.

| 조건 | 시작 임계값 |
|---|---:|
| x축 속도 절댓값 | `0.005 m/s` 이상 |
| y축 속도 절댓값 | `0.005 m/s` 이상 |
| Yaw 각속도 절댓값 | `1 deg/s` 이상 |

명령이 중립으로 돌아오면 진행 중인 Swing 다리를 착지시킨 뒤 마지막으로 유효했던 STANCE 발 위치를 유지한다.

## 6. 보정 모드

보정 모드는 로봇이 걷지 않는 상태에서 몸체 위치와 Yaw 자세를 미세 조정한다. 이 모드에서는 Tripod 보행을 사용하지 않는다.

| 입력 | 명령 | 최대값 |
|---|---|---:|
| Pitch | 몸체 x축 이동 속도 | `±0.05 m/s` |
| Roll | 몸체 y축 이동 속도 | `±0.05 m/s` |
| Throttle | 몸체 z축 이동 속도 | `±0.05 m/s` |
| Yaw | 몸체 Yaw 보정 목표각 | `±10 deg` |

Yaw는 각속도가 아니라 짐벌 위치에 직접 대응하는 목표각이다. Yaw 짐벌을 중립으로 놓으면 보정 목표각도 `0 deg`로 복귀한다. x·y·z 이동과 Yaw 자세 명령도 발의 IK 작업공간 안에서만 갱신하며, 적용할 수 없는 명령은 직전 유효 명령을 유지한다.

## 7. 암 모드

암 모드에서는 짐벌로 매니퓰레이터의 말단 이동과 손목 회전을 명령한다. 다음 배치는 유지하며, 속도 범위와 작업공간 제한값은 매니퓰레이터 제어를 구현할 때 확정한다.

| 입력 | 명령 |
|---|---|
| Throttle | 매니퓰레이터 말단의 z축 이동 속도 |
| Yaw | 매니퓰레이터 손목의 회전 속도 |
| Roll | 매니퓰레이터 말단의 y축 이동 속도 |
| Pitch | 매니퓰레이터 말단의 x축 이동 속도 |
| SA | 그리퍼 열림·닫힘 |

현재 제어 모델에는 암 모드가 구현되어 있지 않다. 구현 전까지 SC의 가운데 상태는 짐벌 명령을 전달하지 않는 READY 상태로 사용한다.

## 8. 자율주행 모드

SB의 한 위치는 최종적으로 자율주행 명령원을 선택하는 데 사용한다. 자율주행 모드에서도 SD Kill은 항상 사용할 수 있어야 한다. 자율주행 명령의 종류와 조종기 수동 개입 방식은 자율주행 제어를 구현할 때 확정한다.

현재 제어 모델에는 자율주행 명령원이 구현되어 있지 않다. 현재 SB는 `1`에서 서기·READY를 유지하고 `0/2`에서 착지를 요청한다.

## 9. 동작 허가와 통신 끊김

서기 또는 착지 중에는 짐벌 명령을 로봇 동작으로 전달하지 않는다. 서기가 끝나 READY 상태가 된 뒤 네 짐벌이 다음 중립 범위에 연속 `0.2 s` 동안 있어야 이동과 보정 명령을 허용한다.

| 입력 | 중립 판정 범위 |
|---|---:|
| Throttle | `±20 raw` |
| Yaw/Roll/Pitch | `±50 raw` |

마지막 정상 CRSF 프레임을 받은 뒤 `100 ms`가 지나면 연결 끊김으로 판단한다. STM32에서는 이때 모든 사용자 이동 명령을 0으로 만들고 보행 및 동작 허가를 해제하여 현재 STANCE 위치를 유지한다. 연결이 복구되어도 네 짐벌이 다시 `0.2 s` 동안 중립을 유지한 뒤에만 동작을 허가한다. 이 처리는 Safety Fault가 아니라 조종 입력 Failsafe이다.

## 10. 실기 보정 항목

실제 조종기와 수신기가 준비되면 다음 항목을 채널별 설정 테이블에 기록한다.

- CRSF 최소·중립·최대 raw 값
- 짐벌 축별 방향 반전 여부
- 스위치 물리 위치와 논리값 `0/1/2`의 대응
- 중립 떨림을 고려한 Dead Zone
- 조종 감각을 고려한 LPF Cutoff와 최대 명령값

보정 전에는 이상적인 `-1000~1000` 입력을 가정한다. 보정 후에도 제어기로 전달하는 최종 형식은 중립 `0`, 범위 `-1000~1000`으로 유지한다.

## 11. 입력 시험 순서

조종기가 없을 때는 임시 입력 생성기로 먼저 시험하고, 이후 저장된 CRSF 프레임과 실제 수신기로 범위를 넓힌다. 아날로그 시험 명령은 중간값을 사용하지 않고 `+1000` 또는 `-1000`을 사용한다. 각 명령을 중립 `0`으로 복귀시키고 해당 동작의 정지 또는 자세 안정이 끝난 뒤에만 다음 시험으로 넘어간다.

보행 최대 명령은 한 걸음 시간인 `0.5 s` 동안 입력하고 다음 보행 전까지 `2.5 s` 이상 중립을 유지한다. 몸체 자세와 보정 명령은 각 방향으로 `1.0 s` 동안 입력하고 반대 방향 시험 전에 `2.0 s` 동안 중립을 유지한다. 여러 이동축의 개별 최대값은 각각 시험하며, 작업공간을 넘는 합성 최대 속도를 만들기 위해 모든 축을 동시에 최대값으로 고정하지 않는다.

1. 네 짐벌이 중립에서 `0`이고 양 끝에서 `-1000/1000`이 되는지 확인한다.
2. 모든 짐벌 Ramp가 중립→최대 `0.2 s`, 최소↔최대 `0.4 s`인지 확인한다.
3. SB로 서기·READY·착지 전환을 확인한다.
4. SC의 조종·중립 READY·보정 선택을 확인한다.
5. SA `0`에서 Throttle 양·음 전진·후진과 Yaw 양·음 회전을 확인한다.
6. SA `1`에서 Throttle과 Yaw를 각각 `±1000`으로 입력하여 x·y 양방향 이동하고 Heading이 유지되는지 확인한다.
7. SA 전환 순간에 이전 Yaw 명령이 회전과 횡이동 사이로 넘어가지 않는지 확인한다.
8. 조종 모드와 보정 모드 전환 순간에 네 짐벌의 이전 명령이 남지 않는지 확인한다.
9. 보정 모드의 x·y·z 양방향 이동과 Yaw `±10 deg` 명령을 확인한다.
10. CRSF가 `100 ms` 끊겼을 때 명령이 0이 되고, 재연결 후 중립 `0.2 s` 전에는 다시 움직이지 않는지 확인한다.
11. SD Kill과 SE 기준값 초기화가 지정된 스위치에서만 동작하는지 확인한다.
12. 암 모드 구현 후 짐벌 네 축과 SA 그리퍼 명령을 확인한다.
13. 자율주행 구현 후 SB 전환과 SD Kill 우선 동작을 확인한다.
