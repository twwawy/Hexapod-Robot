# 드론 조종기 입력

드론 조종기를 이용한 로봇의 수동 조종 방법을 정의한다. 이 문서에서 사용하는 몸체 원점, 몸체 원점 좌표계, 몸체 기준점 및 몸체 기준 좌표계는 [좌표축 README](../좌표축/README.md#몸체-좌표계)의 정의를 따른다.

로봇의 이동은 몸체 원점을 기준으로 수행한다. 로봇이 이동하지 않은 상태에서 몸체 원점의 위치나 몸체의 자세만 변경하는 동작은 로봇의 이동에 포함하지 않는다.

## 입력 처리 구조

조종기 입력은 다음 순서로 처리한다.

```text
USER 또는 실제 RC 입력
        ↓
ControlPriorityManager
        ↓
DroneController
        ↓
각 기능 블록의 Enable 및 명령
```

`ControlPriorityManager`는 조종기 스위치, 완료 신호와 Fault 신호를 이용하여 현재 허용할 동작 모드를 먼저 결정한다. `DroneController`는 허용된 모드에 대해서만 입력 필터, 자세 진행률, 보행 명령과 각 기능 블록의 Enable을 생성한다.

상위 제어 상태의 우선순위는 다음과 같다.

```text
KILL
  > ROLLOVER_FAULT
  > CONTROLLER_FAULT
  > LANDING
  > STANDING
  > READY의 조종 모드 또는 보정 모드
```

서기 또는 착지 중에는 짐벌 입력을 동작 명령으로 전달하지 않는다.

`Motion_Armed`는 READY 진입 직후 남아 있는 조종기 입력으로 로봇이 갑자기 움직이는 것을 막는 내부 동작 허가 상태이다. READY가 아닌 동안에는 해제하고, READY 진입 후 Throttle·Yaw·Roll·Pitch가 0.2초 동안 모두 중립 범위에 있을 때만 활성화한다. `Motion_Armed`가 활성화되기 전에는 조종 모드와 보정 모드의 이동 명령을 전달하지 않는다.

수동 조종 모드에서 `Motion_Armed`가 활성화되어도 READY 상태라는 이유만으로 Tripod 보행을 시작하지 않는다. 다음 조건 중 하나를 만족하는 실제 이동 명령이 있을 때만 `Tripod_Enable=1`로 설정한다.

```text
abs(vx_user) >= Gait_Vx_Threshold
또는
abs(wz_user) >= Gait_Wz_Threshold
```

`Body_Control_Enable`은 Final Gait Body Twist, Stance 발끝 궤적과 몸체 자세 오버레이를 허용하고, `Tripod_Enable`은 Tripod 위상과 Swing 궤적만 허용한다. READY에서 `Motion_Armed=1`이면 조종 모드와 보정 모드의 `Body_Control_Enable`을 활성화한다. `Tripod_Enable=0`일 때도 발끝 목표를 0으로 만들지 않고 6개 다리의 기본 또는 직전 안전 STANCE 목표를 계속 출력한다. 따라서 정지 상태에서도 위치·자세 PI 또는 보정 모드 명령을 수행할 수 있다. 보정 모드에서는 항상 `Tripod_Enable=0`으로 둔다.

## PI 제어 적용 범위

PI 제어기는 기준값과 측정 출력값의 오차를 사용한다.

```text
오차 = 기준값 - 측정값
```

모드별 적용 범위는 다음과 같다.

| 모드 | 입력 | PI 적용 |
|---|---|---|
| 조종 모드 | Throttle | 절대좌표계 x·y Position Reference와 Position PI |
| 조종 모드 | Yaw | Yaw Reference 적분과 Gait Heading Yaw PI를 보행 회전에 적용 |
| 조종 모드 | Roll | Roll 목표각과 단일 몸체 자세 PI를 자세 오버레이에 적용 |
| 조종 모드 | Pitch | Pitch 목표각과 단일 몸체 자세 PI를 자세 오버레이에 적용 |
| 보정 모드 | Yaw | Yaw 보정 목표각과 단일 몸체 자세 PI를 자세 오버레이에 적용 |
| 보정 모드 | x·y·z 이동속도 | PI를 적용하지 않음 |
| 암 모드 | 전체 입력 | PI를 적용하지 않음 |

LANDED, STANDING, LANDING, FAULT, KILL 상태에서는 Position/자세 PI 출력을 0으로 만들고 적분항을 누적하지 않는다. PI가 활성화될 때는 x·y Position Reference와 조종 모드 Yaw Reference를 현재 측정값으로 초기화하고, 보정 모드 Yaw의 기준 Heading도 현재 Yaw로 저장한다. 모든 PI 적분항은 0으로 초기화하여 갑작스러운 명령을 방지한다.

조종 모드 Yaw PI는 보행 Heading을 유지하는 경로이며, 그 출력은 사용자 Yaw 각속도와 합쳐 Tripod 회전 보행에 사용한다. 조종 모드 Roll·Pitch와 보정 모드 Yaw는 이 경로와 분리된 하나의 단일 몸체 자세 PI를 사용한다. 이중 PI나 내부 각속도 PI는 사용하지 않는다.

단일 몸체 자세 PI 출력은 자세 보정 각속도이며, 200 Hz로 적분한 뒤 IK 직전에 6개 발끝 목표에 몸체 원점 기준 역회전으로 적용한다. 따라서 보행 중에도 Roll·Pitch 또는 보정 Yaw 명령이 Tripod 위상, 보폭, Swing 착지점을 변경하지 않고 몸체 자세만 변경한다.

## 짐벌 입력

스위치 SC를 사용하여 짐벌 입력을 조종 모드와 보정 모드 사이에서 전환한다.

### 조종 모드

조종 모드에서는 로봇의 이동 속도, 몸체의 roll·pitch 목표각과 yaw 각속도를 명령한다.

| 입력 채널 | 기능 |
|---|---|
| 스로틀 | 몸체 원점 좌표계의 x축 방향 전진·후진 선속도를 명령한다. |
| yaw | 몸체 원점을 지나는 z축을 기준으로 좌우 회전 각속도를 명령한다. |
| roll | 몸체 원점 좌표계를 기준으로 몸체의 roll 목표각을 명령한다. |
| pitch | 몸체 원점 좌표계를 기준으로 몸체의 pitch 목표각을 명령한다. |

### 암 모드

암 모드에서는 짐벌 입력을 이용하여 매니퓰레이터의 말단 위치와 손목 회전을 조종한다.

| 입력 채널   | 기능                         |
| ------- | -------------------------- |
| 스로틀     | 매니퓰레이터 말단의 z축 방향 이동 속도를 명령한다. |
| yaw     | 매니퓰레이터 손목의 회전 속도를 명령한다.       |
| roll    | 매니퓰레이터 말단의 y축 방향 이동 속도를 명령한다. |
| pitch   | 매니퓰레이터 말단의 x축 방향 이동 속도를 명령한다. |

### 보정 모드

보정 모드에서는 몸체 기준 좌표계를 기준으로 몸체 원점의 이동 속도와 몸체의 yaw 보정 목표각을 명령한다.

| 입력 채널 | 기능 |
|---|---|
| 스로틀 | 몸체 기준 좌표계의 z축 방향으로 몸체 원점의 이동 속도를 명령한다. |
| yaw | 몸체 원점 좌표계를 기준으로 몸체의 yaw 보정 목표각을 명령한다. 조이스틱 입력을 적분하지 않고 최대 보정각에 직접 대응시킨다. |
| roll | 몸체 기준 좌표계의 y축 방향으로 몸체 원점의 이동 속도를 명령한다. |
| pitch | 몸체 기준 좌표계의 x축 방향으로 몸체 원점의 이동 속도를 명령한다. |

보정 모드의 yaw 조이스틱이 중앙으로 복귀하면 yaw 보정 목표각도 0°로 복귀한다. 조종 모드의 Yaw Heading Hold와 달리 보정 모드에서는 조이스틱 입력을 각속도로 적분하지 않는다.

## 스위치 입력

| 스위치 | 기능 |
|---|---|
| SA | 조종 모드에서는 스로틀 입력의 전진·후진 방향을 선택하고, 암 모드에서는 그리퍼의 열림·닫힘을 명령하며, 보정 모드에서는 스로틀 입력의 +z·−z 방향을 선택한다. |
| SB | 착지 모드, 수동 조종 및 자율 주행 모드를 선택한다. |
| SC | 짐벌 입력의 조종 모드, 암 모드 및 보정 모드를 선택한다. |
| SD | 킬 스위치로 사용한다. |
| SE | 몸체 원점을 몸체 기준점으로 일치시키고 몸체의 roll·pitch·yaw 각도를 각각 0°로 복귀시킨다. |
