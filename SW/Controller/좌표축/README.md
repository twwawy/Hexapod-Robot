## 몸체 좌표계

이 문서에서 로봇의 이동은 보행에 의한 전진·후진·좌우 이동 및 좌우 회전을 뜻한다. 몸체의 이동은 로봇이 이동하지 않은 상태에서 몸체의 위치나 자세만 변경하는 동작을 뜻한다.

절대 좌표계 \(\{W\}\)는 지면에 고정된 좌표계이며 로봇의 이동이나 회전에 따라 움직이지 않는다. 모든 관절각이 0°인 최초 착지 상태에서 몸체 원점 \(O_B\)과 절대 좌표계 원점 \(O_W\)을 일치시키고, 두 좌표계의 축 방향도 일치시킨다.

따라서 최초 착지 상태의 몸체 위치는 다음과 같다.

$$
{}^Wp_B
=
\begin{bmatrix}
0\\0\\0
\end{bmatrix}
$$

로봇이 그 자리에서 기본 자세로 일어서면 절대좌표계 기준 \(x\), \(y\) 위치는 유지되고 몸체 높이만 증가하므로 다음과 같이 나타낸다.

$$
{}^Wp_B
=
\begin{bmatrix}
0\\0\\h_{stand}
\end{bmatrix},
\qquad h_{stand}>0
$$

몸체 원점 \(O_B\)는 현재 몸체의 중심에 위치한다. 몸체 원점은 로봇이 이동할 때 로봇과 함께 이동하며, 로봇이 이동하지 않고 몸체만 이동할 때도 몸체를 따라 이동한다.

몸체 원점 좌표계 \(\{B\}\)는 몸체 원점 \(O_B\)를 원점으로 한다. \(+x_B\)축은 로봇의 전진 방향, \(+y_B\)축은 로봇의 왼쪽 방향, \(+z_B\)축은 로봇의 수직 위쪽 방향이며 오른손 좌표계를 따른다.

몸체 기준점 \(O_R\)은 로봇이 기본 자세로 서 있을 때의 명목 몸체 원점이다. 몸체 기준 좌표계 \(\{R\}\)는 몸체 기준점 \(O_R\)을 원점으로 하며, 좌표축 방향은 기본 자세의 몸체 좌표계 \(\{B\}\)와 같다.

몸체 기준점과 몸체 기준 좌표계는 로봇이 이동할 때 로봇을 따라 이동하며, 로봇이 좌우로 회전하면 좌표축도 함께 회전한다. 로봇이 이동하지 않고 몸체의 위치나 자세만 변경할 때는 몸체 기준점과 몸체 기준 좌표계가 이동하거나 회전하지 않는다.

몸체 좌표계 \(\{B\}\)에서 몸체 원점 자체의 좌표는 항상 0이다. 로봇의 실제 이동 거리와 높이는 고정된 절대 좌표계 \(\{W\}\)에서 표현한다. Body Position Estimator는 \({}^W\hat p_B\)를 계산하고, 현재 Position PI는 그중 x·y 위치와 목표 \({}^Wp_{B,ref}^{xy}\)만 사용한다. z 위치는 추정과 검증에는 사용하지만 Position PI에는 입력하지 않는다.

조종 모드 Throttle과 Yaw가 만드는 보행 위치·Heading은 몸체 기준 좌표계 \(\{R\}\)의 명목 이동으로 처리한다. 조종 모드 Roll·Pitch와 보정 모드 Yaw는 실제 몸체 좌표계 \(\{B\}\)를 같은 몸체 원점에서 \(\{R\}\)에 대해 회전시키는 자세 오버레이로 처리한다. \({}^Rp_{F_i}^{base}\)는 `Tripod_Enable=1`일 때의 Tripod 발끝 목표 또는 `Tripod_Enable=0`일 때의 기본·직전 안전 STANCE 목표이다. 이 기준 발끝 목표는 IK 직전에 다음과 같이 몸체 좌표계로 역회전한다.

$$
{}^Bp_{F_i}^{cmd}
=
({}^RR_B)^T
{}^Rp_{F_i}^{base}
$$

이 변환은 평행이동을 추가하지 않으며, Tripod 위상·보폭·Swing 착지점을 바꾸지 않고 몸체 원점 기준 자세만 변경한다.

## 착지 자세와 기본 자세의 정의

로봇의 최초 착지 자세는 모든 관절각이 0°인 상태이며, 이때 몸체 원점을 절대 좌표계의 원점으로 초기화한다.

로봇의 기본 자세는 6개 다리가 모두 1번 관절 0°, 2번 관절 30°, 3번 관절 50°일 때이다. 기본 자세로 서기 완료한 순간에는 몸체 기준 좌표계 \(\{R\}\)의 원점을 현재 몸체 원점에 맞추므로 로컬 기준 위치는 0이지만, 절대 좌표계에서는 몸체 높이 \(h_{stand}\)만큼 양의 z 위치를 가진다.

착지 자세와 기본 자세 사이의 실제 서기·앉기 발 궤적 및 상태전환은 전체 제어기 통합의 마지막 단계에서 별도로 설계한다. 현재 정의는 두 자세의 좌표계 원점과 위치 관계만 규정한다.

$$

\begin{bmatrix}

0\\
-0.287006
\end{bmatrix}
\mathrm{m}
$$

## 발끝 좌표 정의

다리 i의 발끝점 P_i는 로봇의 초기 자세에서 해당 다리의 1번 관절 좌표계를 기준으로 나타낸다. 이 좌표계의 원점 O_i는 다리 i의 1번 관절 중심이며, 좌표축 방향은 로봇의 초기 자세일 때 1번 관절 좌표축의 방향으로 고정한다.

예를 들어 1번 다리의 발끝점 P_1은 초기 자세에서 1번 다리의 1번 관절 좌표축과 원점을 기준으로 하며, x_1, y_1, z_1으로 나타낸다.

```text
P_1 = (x_1, y_1, z_1)
```

일반적으로 다리 i의 발끝점은 다음과 같이 나타낸다.

```text
P_i = (x_i, y_i, z_i),  i = 1, 2, 3, 4, 5, 6
```

## 몸체 좌표계와 다리 좌표계의 변환

몸체 좌표계에서 본 다리 i의 원점 O_i를 `(o_xi, o_yi, o_zi)`, 몸체 좌표계에 대한 다리 좌표계의 z축 회전각을 `α_i`라고 한다.

몸체 좌표계의 점 `(x_B, y_B, z_B)`를 다리 i의 원점 좌표계 `(x_i, y_i, z_i)`로 변환하는 식은 다음과 같다.

```text
x_i =  (x_B - o_xi) cos(α_i) + (y_B - o_yi) sin(α_i)
y_i = -(x_B - o_xi) sin(α_i) + (y_B - o_yi) cos(α_i)
z_i =   z_B - o_zi

i = 1, 2, 3, 4, 5, 6
```

반대로 다리 i의 원점 좌표계에서 몸체 좌표계로 변환하는 식은 다음과 같다.

```text
x_B = o_xi + x_i cos(α_i) - y_i sin(α_i)
y_B = o_yi + x_i sin(α_i) + y_i cos(α_i)
z_B = o_zi + z_i
```

각 다리 원점의 정확한 위치와 좌표축 방향, 블록 연결 및 초기 자세 설정은 [initial_position.slx](./initial_position.slx)를 직접 열어 확인한다.
