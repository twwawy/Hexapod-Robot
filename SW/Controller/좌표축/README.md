## 몸체 좌표계

이 문서에서 로봇의 이동은 보행에 의한 전진·후진·좌우 이동 및 좌우 회전을 뜻한다. 몸체의 이동은 로봇이 이동하지 않은 상태에서 몸체의 위치나 자세만 변경하는 동작을 뜻한다.

몸체 원점 \(O_B\)는 현재 몸체의 중심에 위치한다. 몸체 원점은 로봇이 이동할 때 로봇과 함께 이동하며, 로봇이 이동하지 않고 몸체만 이동할 때도 몸체를 따라 이동한다.

몸체 원점 좌표계 \(\{B\}\)는 몸체 원점 \(O_B\)를 원점으로 한다. \(+x_B\)축은 로봇의 전진 방향, \(+y_B\)축은 로봇의 왼쪽 방향, \(+z_B\)축은 로봇의 수직 위쪽 방향이며 오른손 좌표계를 따른다.

몸체 기준점 \(O_R\)은 로봇이 초기 자세일 때의 몸체 원점 \(O_B\)이다. 몸체 기준 좌표계 \(\{R\}\)는 몸체 기준점 \(O_R\)을 원점으로 하며, 좌표축 방향은 로봇이 초기 자세일 때의 몸체 원점 좌표계 \(\{B\}\)와 같다.

몸체 기준점과 몸체 기준 좌표계는 로봇이 이동할 때 로봇을 따라 이동하며, 로봇이 좌우로 회전하면 좌표축도 함께 회전한다. 로봇이 이동하지 않고 몸체의 위치나 자세만 변경할 때는 몸체 기준점과 몸체 기준 좌표계가 이동하거나 회전하지 않는다.

## 발끝 좌표 정의

다리 i의 발끝점 P_i는 로봇의 초기 자세에서 해당 다리의 1번 관절 좌표계를 기준으로 나타낸다. 이 좌표계의 원점 O_i는 다리 i의 1번 관절 중심이며, 좌표축 방향은 로봇의 초기 자세일 때 1번 관절 좌표축의 방향으로 고정한다.

예를 들어 1번 다리의 발끝점 P_1은 초기 자세에서 1번 다리의 1번 관절 좌표축과 원점을 기준으로 하며, x_1, y_1, z_1으로 나타낸다.

```text
P_1 = (x_1, y_1, z_1)
```

일반적으로 다리 i의 발끝점은 다음과 같이 나타낸다.

```text
P_i = (x_i, y_i, z_i),  i = 1, 2, 3, 4, 5, 6
```

## 몸체 좌표계와 다리 좌표계의 변환

몸체 좌표계에서 본 다리 i의 원점 O_i를 `(o_xi, o_yi, o_zi)`, 몸체 좌표계에 대한 다리 좌표계의 z축 회전각을 `α_i`라고 한다.

몸체 좌표계의 점 `(x_B, y_B, z_B)`를 다리 i의 원점 좌표계 `(x_i, y_i, z_i)`로 변환하는 식은 다음과 같다.

```text
x_i =  (x_B - o_xi) cos(α_i) + (y_B - o_yi) sin(α_i)
y_i = -(x_B - o_xi) sin(α_i) + (y_B - o_yi) cos(α_i)
z_i =   z_B - o_zi

i = 1, 2, 3, 4, 5, 6
```

반대로 다리 i의 원점 좌표계에서 몸체 좌표계로 변환하는 식은 다음과 같다.

```text
x_B = o_xi + x_i cos(α_i) - y_i sin(α_i)
y_B = o_yi + x_i sin(α_i) + y_i cos(α_i)
z_B = o_zi + z_i
```

각 다리 원점의 정확한 위치와 좌표축 방향, 블록 연결 및 초기 자세 설정은 [initial_position.slx](./initial_position.slx)를 직접 열어 확인한다.
