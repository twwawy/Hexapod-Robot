# 좌표계와 관절 정의

6족 로봇의 다리 번호, 관절 방향, 몸체·다리 좌표계와 기본 자세를 정의한다. 제어기와 STM32 기구학 코드는 모두 이 문서의 부호 규칙을 사용한다.

## 1. 다리와 관절 번호

![다리 번호](./다리%20번호.png)

각 다리의 관절은 몸체에서 가까운 순서로 1번, 2번, 3번이다. 1_3은 1번 다리의 3번 관절을 뜻한다.

![다리 관절 번호와 0도 자세](./다리%20관절%20번호.png)

모든 관절의 제어 사용 범위는 -135~135 deg이다. 각 관절은 자신의 +Z축을 중심으로 회전하며 양의 각도는 오른손 법칙을 따른다.

## 3. 좌표계

| 기호 | 이름 | 원점과 용도 |
|---|---|---|
| \(\{W\}\) | 절대 좌표계 | 지면에 고정하며 전역 위치를 표현한다. |
| \(\{B\}\) | 몸체 좌표계 | 현재 몸체 중심 \(O_B\)에 고정한다. |
| \(\{R\}\) | 몸체 기준 좌표계 | 기본 자세의 명목 몸체 기준점 \(O_R\)에 둔다. |
| \(\{L_i\}\) | 다리 좌표계 | i번 다리 1번 관절 중심 \(O_i\)에 둔다. |

몸체 축은 다음 오른손 좌표계를 사용한다.

| 축 | 방향 |
|---|---|
| \(+X\) | 로봇 전진 |
| \(+Y\) | 로봇 왼쪽 |
| \(+Z\) | 로봇 수직 위쪽 |

WT931도 +X 전진, +Y 왼쪽, +Z 위쪽이 되도록 장착한다. 실제 센서 시험에서는 각 축의 부호와 정지 Offset을 확인한다.

## 4. 절대 원점과 몸체 기준점

모든 관절이 0 deg인 최초 착지 상태에서 \(O_W=O_B\)로 초기화하고 축 방향도 일치시킨다.

\[
{}^Wp_B=
\begin{bmatrix}
0\\
0\\
0
\end{bmatrix}
\]

그 자리에서 기본 자세로 일어서면 x·y 위치는 유지되고 몸체 높이만 증가한다.

\[
{}^Wp_B=
\begin{bmatrix}
0\\
0\\
h_{stand}
\end{bmatrix}
\]

\(\{B\}\)는 실제 몸체 위치와 자세를 따라간다. \(\{R\}\)는 로봇의 명목 보행 이동과 Yaw를 따라가지만, 보행하지 않은 상태에서 수행하는 몸체 위치·Roll·Pitch·보정 Yaw 동작의 기준으로 남는다.

## 5. 착지 자세와 기본 자세

| 자세 | 관절각 |
|---|---|
| 최초 착지 | 모든 관절 0 deg |
| 기본 서기 | 각 다리 \(q_1=0\,deg,\ q_2=30\,deg,\ q_3=50\,deg\) |

기본 자세의 다리 로컬 발끝 위치는 다음과 같다.

\[
{}^{L_i}p_{0,i}=
\begin{bmatrix}
0.218728\\
0\\
-0.287006
\end{bmatrix}
\mathrm{m}
\]

![기본 자세 정면](./초기%20자세%20정면.png)

![기본 자세 전체 형상](./초기%20자세%20전체%20형상.png)

서기와 착지는 현재 제어 모델에서 각각 5.6 s의 자세 변화와 0.5 s의 안정 확인 시간을 사용한다.

## 6. 발끝과 다리 장착 방향

i번 다리의 발끝은 다리 좌표계에서 다음처럼 표현한다.

\[
{}^{L_i}p_{F_i}=
\begin{bmatrix}
x_i\\
y_i\\
z_i
\end{bmatrix}
\]

몸체 기준 다리 바깥 방향 각도는 다음과 같다.

| 다리 | \(\alpha_i\) |
|---:|---:|
| 1 | -45 deg |
| 2 | -90 deg |
| 3 | -135 deg |
| 4 | 45 deg |
| 5 | 90 deg |
| 6 | 135 deg |

정확한 다리 원점 \({}^Bp_{L_i}\)은 [parameters.m](parameters.m)과 [initial_position.slx](initial_position.slx)의 기구 파라미터를 기준으로 한다.

## 7. 좌표 변환

몸체 좌표계에서 본 다리 원점을 \((o_{xi},o_{yi},o_{zi})\), 다리 장착각을 \(\alpha_i\)라 하면 몸체 좌표를 다리 좌표로 변환하는 식은 다음과 같다.

\[
\begin{aligned}
x_i &= (x_B-o_{xi})\cos\alpha_i+(y_B-o_{yi})\sin\alpha_i,\\
y_i &=-(x_B-o_{xi})\sin\alpha_i+(y_B-o_{yi})\cos\alpha_i,\\
z_i &=z_B-o_{zi}.
\end{aligned}
\]

반대 변환은 다음과 같다.

\[
\begin{aligned}
x_B &=o_{xi}+x_i\cos\alpha_i-y_i\sin\alpha_i,\\
y_B &=o_{yi}+x_i\sin\alpha_i+y_i\cos\alpha_i,\\
z_B &=o_{zi}+z_i.
\end{aligned}
\]

회전행렬로 표현하면 다음과 같다.

\[
{}^{L_i}p_F=
({}^BR_{L_i})^T
\left(
{}^Bp_F-{}^Bp_{L_i}
\right)
\]

자세 오버레이와 FK/IK 계산은 [제어기 상세 설계](../Controller_detail.md)를 따른다.
